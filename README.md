# Βοηθός RAG με παραπομπές για νηπιαγωγούς (πρωτότυπο)

Πρωτότυπο που απαντά σε ερωτήσεις νηπιαγωγών από το **Πρόγραμμα Σπουδών Προσχολικής Εκπαίδευσης** (Διευρυμένη Εκδοχή, 2η έκδοση 2022, ΙΕΠ), δείχνοντας για κάθε απάντηση το απόσπασμα, την υποενότητα και τη σελίδα από την οποία προέρχεται. Έγινε ως δοκιμαστική εργασία για υποψηφιότητα διδακτορικού.

**Κανόνες χρήσης.** Χρησιμοποιείται μόνο δημόσιο υλικό. Δεν χρησιμοποιούνται και δεν πρέπει να εισάγονται δεδομένα παιδιών ή εκπαιδευτικών. Το πρωτότυπο δεν είναι για πραγματική χρήση: οι απαντήσεις περιέχουν σφάλματα (βλ. «Αποτελέσματα» και «Περιορισμοί»), και κάθε παραπομπή πρέπει να ελέγχεται στο Πρόγραμμα.

**Χρήση εργαλείου AI.** Ο κώδικας γράφτηκε με τη βοήθεια εργαλείου AI (Claude), κάτι που επιτρέπεται από τους κανόνες της εργασίας. Οι ερωτήσεις, οι σημειώσεις «τι περιέχει το υλικό» και τα σημειώματα της εργασίας προετοιμάστηκαν επίσης με τη βοήθεια εργαλείου AI. Οι απαντήσεις βαθμολογήθηκαν χωριστά από τον συγγραφέα και από εργαλείο AI.

## Πώς λειτουργεί

```
PDF (σ.28–37 Γλώσσα, σ.62–73 Μαθηματικά)
  → ingest.py        εξαγωγή του πίνακα ανά στήλη, κανονικοποίηση τόνων (NFC), 136 chunks
  → embed_index.py   embeddings (multilingual-e5-base) → ChromaDB
  → retrieve.py      ισορροπημένη ανάκτηση: 3 αποτελέσματα + 6 δραστηριότητες + 1 εισαγωγή
  → rag.py           prompt → Krikri-8B (llama.cpp) → απάντηση με αριθμημένες παραπομπές
```

Το μοντέλο γράφει μόνο αριθμούς παραπομπής, όπως `[2]`. Ο κώδικας τους αντιστοιχίζει σε υποενότητα και σελίδα και επισημαίνει αριθμούς που δεν αντιστοιχούν σε απόσπασμα. **Ο έλεγχος αυτός δεν αποδεικνύει ότι το απόσπασμα στηρίζει τον ισχυρισμό**: αυτό κρίνεται χειρωνακτικά στην αξιολόγηση.

## Απαιτήσεις

- Δοκιμάστηκε σε MacBook Air M1 με 16 GB, Python 3.10. Η εκτέλεση 30 ερωτήσεων με RAG πήρε περίπου 12 λεπτά.
- **Πρόγραμμα Σπουδών (PDF):** κατέβασέ το από το ΙΕΠ και τοποθέτησέ το ως `data/raw/programma_spoudon.pdf`. Δεν περιλαμβάνεται στο αποθετήριο.
- **Γλωσσικό μοντέλο:** `llama-krikri-8b-instruct-q4_k_m.gguf` (περίπου 5 GB) από το `ilsp/Llama-Krikri-8B-Instruct-GGUF` στο Hugging Face, στον φάκελο `models/`.

## Εγκατάσταση

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
pip install llama-cpp-python==0.3.30 --only-binary=llama-cpp-python \
    --extra-index-url https://abetlen.github.io/llama-cpp-python/whl/metal --no-cache-dir
python -c "from huggingface_hub import hf_hub_download; hf_hub_download('ilsp/Llama-Krikri-8B-Instruct-GGUF', 'llama-krikri-8b-instruct-q4_k_m.gguf', local_dir='models')"
```

Σημείωση: χρησιμοποιήθηκε η έκδοση 0.3.30 της `llama-cpp-python`, γιατί το έτοιμο πακέτο της 0.3.36 απέτυχε στην εγκατάσταση (σφάλμα `Bad CRC-32`) στο περιβάλλον δοκιμής. Εναλλακτικά: `CMAKE_ARGS="-DGGML_METAL=on" pip install llama-cpp-python`.

## Εκτέλεση

```bash
# 1. Εξαγωγή κειμένου και chunks (πρέπει να γράψει 136 chunks)
python src/ingest.py --activity-per-bullet --out data/processed/chunks_v5.jsonl

# 2. Ευρετήριο (την πρώτη φορά κατεβάζει το μοντέλο embeddings, περίπου 1 GB)
python src/embed_index.py --chunks data/processed/chunks_v5.jsonl --index-dir data/index_v5

# 3. Ερώτηση
python src/rag.py --index-dir data/index_v5 --k-activity 6 "Ποιες δραστηριότητες υπάρχουν με την αριθμογραμμή;"

# Άλλες λειτουργίες
python src/rag.py --index-dir data/index_v5 --k-activity 6 --interactive
python src/rag.py --index-dir data/index_v5 --k-activity 6 --batch eval/questions_E1.txt --out results/E1
python src/rag.py --index-dir data/index_v5 --no-rag --batch eval/questions_E2.txt --out results/E2   # χωρίς ανάκτηση
python src/rag.py --index-dir data/index_v5 --k-activity 6 --show-prompt "ερώτηση"                 # τι είδε το μοντέλο
```

Παράδειγμα εξόδου: η απάντηση, η λίστα «Πηγές που αναφέρονται στην απάντηση» (υποενότητα, σελίδα) και η γραμμή «Ανακτήθηκαν» με τα αναγνωριστικά και τα scores των αποσπασμάτων.

**10 ενδεικτικές ερωτήσεις και απαντήσεις:** `results/10_questions_answers.md` (ανεπεξέργαστες, δεν έχουν διορθωθεί).

## Ρυθμίσεις της παγωμένης έκδοσης (v5)

| Στοιχείο | Τιμή |
|---|---|
| Σώμα κειμένων | Γλώσσα σ.28–37, Μαθηματικά σ.62–73: 136 chunks (13 εισαγωγικά, 47 αποτελέσματα, 76 δραστηριότητες) |
| Chunks | αποτελέσματα ομαδοποιημένα ανά κατηγορία (έως 700 χαρακτήρες), μία δραστηριότητα ανά chunk, επικεφαλίδα με υποενότητα στο κείμενο |
| Embeddings | `intfloat/multilingual-e5-base`, επικεφαλίδα και σώμα |
| Ανάκτηση | 3 αποτελέσματα + 6 δραστηριότητες + 1 εισαγωγή (από την ίδια ενότητα με το καλύτερο αποτέλεσμα) |
| Μοντέλο | Krikri-8B-Instruct, Q4_K_M, παράθυρο 6144 tokens, θερμοκρασία 0,1 |
| Prompt | `SYSTEM_RAG` στο `src/rag.py` (απάντηση μόνο από τα αποσπάσματα, αριθμημένες παραπομπές, ρητή άρνηση) |

## Πώς αλλάζω κάτι

| Θέλω να αλλάξω | Πού |
|---|---|
| Μέγεθος chunks | `--max-chars` στο `ingest.py` (προεπιλογή 700), και ξαναφτιάχνω ευρετήριο |
| Μία δραστηριότητα ανά chunk ή ομαδοποίηση | `--activity-per-bullet` στο `ingest.py` |
| Μοντέλο embeddings | `MODEL_NAME` στο `src/common.py` ή `--model` στα `embed_index.py`, `retrieve.py`, `rag.py` (χρειάζεται νέο `--index-dir`) |
| Πόσα αποσπάσματα | `--k-outcome`, `--k-activity` στο `rag.py` |
| Γλωσσικό μοντέλο | `--llm διαδρομή.gguf` στο `rag.py` |
| Prompt | `SYSTEM_RAG` στο `src/rag.py` |
| Σελίδες και ενότητες του σώματος κειμένων | `SECTIONS` στο `src/ingest.py` |

## Αξιολόγηση

- `eval/questions_E1.txt`: 10 ερωτήσεις (Εργασία 1). `eval/questions_E2.txt`: 30 ερωτήσεις (Εργασία 2): 23 με κάλυψη στο υλικό και 7 χωρίς.
- `eval/questions_draft.csv`: τύπος, αναμενόμενη συμπεριφορά και πρόχειρη σημείωση «τι περιέχει το υλικό» (με σελίδα) για κάθε ερώτηση. Οι σημειώσεις έγιναν με βοήθεια AI και χρειάζονται επαλήθευση στο PDF.
- **Φύλλο βαθμολόγησης:** `pip install openpyxl` και `python src/make_scoring_sheet.py` φτιάχνει το `results/scoring_sheet.xlsx` με δύο ξεχωριστές βαθμολογίες ανά απάντηση: ορθότητα (σωστό, μερικώς σωστό, λάθος, επινοημένο) και παραπομπή (στηρίζει, εν μέρει, δεν στηρίζει).
- **Μέτρηση ανάκτησης:** `python src/retrieval_eval.py --index-dir data/index_v5 --k-activity 6 -v` ελέγχει αν οι φράσεις-στόχοι (`eval/retrieval_gold.json`) φτάνουν στο μοντέλο.
- `eval/claude_scores.json`: η βαθμολογία του εργαλείου AI (δεύτερος βαθμολογητής). Το συμπληρωμένο φύλλο με τη βαθμολογία του συγγραφέα στάλθηκε μαζί με την εργασία.

## Αποτελέσματα

Οι τιμές του πίνακα είναι της βαθμολόγησης του εργαλείου AI. Ο συγγραφέας βαθμολόγησε χωριστά και διαφώνησε σε 3 από τις 59 βαθμολογίες ορθότητας: Ε8 και Ε9 με RAG (σωστό αντί επινοημένο και λάθος) και Ε18 χωρίς RAG (μερικώς σωστό αντί επινοημένο). Συμφωνία: 28 από 30 στην ορθότητα με RAG, 28 από 29 χωρίς RAG και 30 από 30 στην παραπομπή (η Ε10 χωρίς RAG δεν βαθμολογήθηκε από τον συγγραφέα). Με τη βαθμολογία του συγγραφέα, οι σωστές απαντήσεις με RAG είναι 15.

| Ορθότητα | Με RAG | Χωρίς RAG |
|---|---|---|
| Σωστό | 13 | 1 |
| Μερικώς σωστό | 12 | 20 |
| Λάθος | 2 | 5 |
| Επινοημένο | 3 | 4 |

Στις 7 ερωτήσεις χωρίς κάλυψη, το RAG αρνήθηκε σωστά και τις 7, ενώ χωρίς RAG καμία απάντηση δεν ήταν σωστή. Στις 23 ερωτήσεις με κάλυψη, οι λάθος και επινοημένες απαντήσεις ήταν 5 και με τις δύο συνθήκες. Από τις 22 απαντήσεις με παραπομπές, 9 είχαν παραπομπές που στηρίζουν πλήρως τον ισχυρισμό, 12 εν μέρει και 1 καθόλου· καμία δεν είχε άκυρο αριθμό παραπομπής.

Η ανάλυση σφαλμάτων περιγράφεται στο σημείωμα της Εργασίας 2. Οι τρεις βασικές αιτίες: το σχετικό υλικό δεν ανακτήθηκε (8 ερωτήσεις), το μοντέλο παρερμήνευσε υλικό που είχε (π.χ. παρουσιάζει αποτελέσματα ως δραστηριότητες), και το μοντέλο επινόησε δραστηριότητες και τις παρέπεμψε σε αποσπάσματα που δεν τις περιέχουν.

## Τι δοκιμάστηκε και απορρίφθηκε

- **Μικρότερα chunks (400 χαρακτήρες)** και **embeddings `BAAI/bge-m3`**: δεν βελτίωσαν την ανάκτηση σε σχέση με το e5-base στην πρώτη μέτρηση.
- **Embedding μόνο του σώματος (χωρίς επικεφαλίδα):** καλύτερο στις ερωτήσεις ρύθμισης, χειρότερο στις υπόλοιπες, άρα θόρυβος.
- **Δύο γύροι αλλαγών στο prompt** με αρνητικές οδηγίες («μην ισχυριστείς ότι…»): το Krikri-8B Q4 συνέχισε να κάνει τα ίδια σφάλματα.
- Στη μέτρηση ανάκτησης (φράσεις-στόχοι), η ρύθμιση 3 αποτελέσματα + 6 δραστηριότητες έδωσε 0,75 στις ερωτήσεις ρύθμισης και 0,73 στις υπόλοιπες, έναντι 0,67 και 0,69 με 3 δραστηριότητες.

## Περιορισμοί

- 30 ερωτήσεις, μία εκτέλεση ανά συνθήκη και δύο βαθμολογητές (ο συγγραφέας και εργαλείο AI) που δεν είναι πλήρως ανεξάρτητοι, γιατί χρησιμοποίησαν τις ίδιες σημειώσεις για το τι περιέχει το υλικό: τα αποτελέσματα είναι ενδείξεις και όχι στατιστικά τεκμηριωμένες διαφορές.
- Οι ερωτήσεις 1–10 χρησιμοποιήθηκαν για τη ρύθμιση της ανάκτησης και του prompt και οι 11–23 για την απόρριψη μίας ρύθμισης ανάκτησης, άρα τα αποτελέσματά τους είναι αισιόδοξα.
- Η ανάκτηση φέρνει όλο το απαραίτητο υλικό σε περίπου τις μισές ερωτήσεις (11 από 23 στη μέτρηση με φράσεις-στόχους).
- Το PDF αποθηκεύει πολλούς τόνους ως ξεχωριστούς χαρακτήρες (U+0301). Το κείμενο κανονικοποιείται σε NFC, αλλά η επίδραση στο Krikri δεν μετρήθηκε. Τα αποτελέσματα που αναφέρονται προέρχονται από την έκδοση με NFC.
- Η αξιολόγηση «χωρίς RAG» κρίνεται ως προς ένα Πρόγραμμα που το μοντέλο δεν είδε.

## Δομή

```
src/        ingest.py, embed_index.py, retrieve.py, rag.py, retrieval_eval.py, make_scoring_sheet.py, common.py
eval/       ερωτήσεις, πρόχειρο gold, φράσεις-στόχοι ανάκτησης, προσωρινή βαθμολογία AI
data/       raw/ (το PDF, δεν περιλαμβάνεται), processed/chunks_v5.jsonl, index_v5/ (παράγεται)

```

Το Πρόγραμμα Σπουδών ανήκει στο ΙΕΠ και δεν αναδιανέμεται εδώ. Για τα μοντέλα ισχύουν οι άδειες που αναγράφονται στις σελίδες τους στο Hugging Face.
